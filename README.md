# 配料猜猜猜 🦊

> **看配料表 · 猜食品 · 涨知识** — 一款轻量微信小游戏

## 项目简介

屏幕上展示一份神秘配料表，玩家从4个选项中猜出对应的食品。每道题答完后，狐狸主厨「豆豆」会给出毒舌吐槽和冷知识。10题一轮，按得分获得 S/A/B/C/D 评级。

## 技术栈

- Canvas 原生渲染（无第三方引擎）
- 微信小游戏 `require` 模块机制
- 云开发 CloudBase（可与「配料表侦探」复用）

## 游戏玩法

- **首页** → 选择分类 → 开始答题
- **答题页**：查看配料表 → 15秒内选择答案 → 狐狸反馈
- **结算页**：显示评级、得分，支持再来一局
- **计分**：基础10分 + 速度加成（最快+5分）+ 连击加成
- **生命**：❤️❤️❤️ 3条命，答错扣1条，用完即游戏结束
